PULSAREX - CURRENT SOURCE GUI LAUNCHER

1. Open the current source folder. On a new setup, run Install-PULSAR.cmd once.
2. Double-click Start-PULSAR.cmd.
3. Select LAN (same Wi-Fi).
4. Keep the generated six-digit PIN, or use Generate PIN. The PIN is not saved to disk.
5. Choose Synthetic demonstration or Live microphone, then click Start server.
6. Click Copy LAN link and open it on the other device on the same Wi-Fi.
7. Click Copy PIN and enter that PIN in the dashboard login.

Open dashboard opens the dashboard on this computer.
Stop server, or closing the launcher, stops its server and microphone capture.
Local only keeps access on this computer.

Port 8765 is the default. If it is in use, select a different port.
Use a trusted private LAN. The launcher does not change firewall/router settings.
Detailed instructions: docs/gui-launcher.md
Archive cleanup: Event archive > Clear archive, then confirm.
